# Python SDK

The official PyGate SDK for Python is [`pygate`](https://pypi.org/project/pygate/). It targets Python 3.9+ and ships with type hints.

## Install

```bash
pip install pygate
```

## Initialize

```python
from pygate import Pygate

client = Pygate(api_key=os.environ["PYGATE_API_KEY"])
```

## Create an order

```python
order = client.orders.create(
    amount=250,
    description="Test order",
    currency="ETB",
    expires_in_seconds=600,  # optional
    metadata={"internal_id": "123"},  # optional
)

print(order.payment_url)
```

## Retrieve an order

```python
order = client.orders.get("ord_3x4mpl3t3st0rd3r1d2")
print(order.status)  # "PENDING" | "PAID" | "EXPIRED" | "REJECTED"
```

## Verify a reference

```python
result = client.verify(reference="TXN9X9K7M", suffix="250")

if result.ok:
    print(result.data.amount)
else:
    print(result.error)
```

## Webhook verification

```python
from pygate.webhooks import verify_webhook

def handle(request):
    raw = request.body  # bytes, not the parsed JSON
    ok = verify_webhook(
        payload=raw,
        signature=request.headers["X-PyGate-Signature"],
        timestamp=request.headers["X-PyGate-Timestamp"],
        secret=os.environ["PYGATE_WEBHOOK_SECRET"],
        tolerance=300,  # seconds
    )
    if not ok:
        return 401, "bad signature"

    delivery_id = request.headers["X-PyGate-Delivery-Id"]

    # ...
    return 200, "ok"
```

## Error handling

All exceptions inherit from `PygateError`:

```python
from pygate import PygateError, PygateRateLimitError

try:
    order = client.orders.create(...)
except PygateRateLimitError as e:
    print("Rate limited; retry after", e.retry_after_seconds)
except PygateError as e:
    print(f"PyGate error {e.status_code}: {e}")
```

## Django / Flask integration

```python
# Django
from django.http import HttpResponse
from pygate import Pygate

client = Pygate(api_key=settings.PYGATE_API_KEY)

def create_order(request):
    order = client.orders.create(
        amount=100,
        description=request.POST["name"],
        currency="ETB",
    )
    return JsonResponse({"payment_url": order.payment_url})
```

  Async support: `Pygate` is sync by default but `PygateAsync` is available with full `asyncio` support. Same API, every method is `async`.
</Callout>
