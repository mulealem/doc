# Create a project

<Endpoint method="POST" path="/api/v1/admin/projects" auth="Authorization: Bearer" />

Creates a new project. The project's `apiKey` is returned **once** in this response — the credential your merchant's integration will use.

## Request body

<Params>
  <Param name="name" type="string" required>
    Project name, 2–100 characters.
  </Param>
  <Param name="callbackUrl" type="string" required>
    Legacy payment callback URL. Must be `https://` and publicly resolvable (SSRF-checked).
  </Param>
  <Param name="description" type="string">
    Optional description.
  </Param>
  <Param name="theme" type="string" default="violet" enum="violet, emerald, rose, amber, blue, slate">
    Checkout page theme.
  </Param>
  <Param name="ownerEmail" type="string">
    Email of an existing Payo user to own the project. Falls back to the platform account bound to the admin key.
  </Param>
</Params>

## Example

<Tabs items={["cURL", "Node", "Python"]}>
  <Tab value="cURL">
    ```bash
    curl -X POST https://dashboard.example.com/api/v1/admin/projects \
      -H "Authorization: Bearer pka_test_4b1c2d3e4f5g6h7i8j9k0l1m2n3o4p5q6r" \
      -H "content-type: application/json" \
      -d '{
        "name": "Coffee Shop Demo",
        "callbackUrl": "https://merchant.example.com/payments/callback",
        "ownerEmail": "merchant@example.com"
      }'
    ```
  </Tab>
  <Tab value="Node">
    ```ts
    const res = await fetch("https://dashboard.example.com/api/v1/admin/projects", {
      method: "POST",
      headers: {
        "Authorization": "Bearer " + process.env.PYGATE_ADMIN_KEY,
        "content-type": "application/json",
      },
      body: JSON.stringify({
        name: "Coffee Shop Demo",
        callbackUrl: "https://merchant.example.com/payments/callback",
      }),
    });
    const body = await res.json();
    console.log(body.project.apiKey); // store this for the merchant
    ```
  </Tab>
  <Tab value="Python">
    ```python
    import requests

    res = requests.post(
        "https://dashboard.example.com/api/v1/admin/projects",
        headers={
            "Authorization": "Bearer " + os.environ["PYGATE_ADMIN_KEY"],
            "Content-Type": "application/json",
        },
        json={
            "name": "Coffee Shop Demo",
            "callbackUrl": "https://merchant.example.com/payments/callback",
        },
    )
    print(res.json()["project"]["apiKey"])
    ```
  </Tab>
</Tabs>
