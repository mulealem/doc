# Update a project

Update name, description, callback URL, or theme.

- Admin tier: <Endpoint method="PATCH" path="/api/v1/admin/projects/{projectId}" auth="Authorization: Bearer" />
- Project tier: <Endpoint method="PATCH" path="/api/v1/projects/me" auth="x-api-key" />

## Request body

All fields are optional; send only the ones you want to change.

<Params>
  <Param name="name" type="string">
    New project name, 2–100 characters.
  </Param>
  <Param name="description" type="string">
    New description. Pass `null` to clear.
  </Param>
  <Param name="callbackUrl" type="string">
    Must be `https://` and publicly resolvable (SSRF-checked).
  </Param>
  <Param name="theme" type="string" enum="violet, emerald, rose, amber, blue, slate">
    Checkout page theme.
  </Param>
</Params>

## Example

```bash
curl -X PATCH https://dashboard.example.com/api/v1/projects/me \
  -H "x-api-key: pgk_test_4b1c2d3e4f5g6h7i" \
  -H "content-type: application/json" \
  -d '{
    "name": "Coffee Shop Demo (updated)",
    "theme": "emerald"
  }'
```
