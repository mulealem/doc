# List projects

## List all projects (admin)

<Endpoint method="GET" path="/api/v1/admin/projects" auth="Authorization: Bearer" />

Paginated list of every project on the platform.

### Query parameters

<Param name="limit" type="number" default="20">
  Page size, 1–100.
</Param>
<Param name="offset" type="number" default="0">
  Number of rows to skip.
</Param>

```bash
curl "https://dashboard.example.com/api/v1/admin/projects?limit=20&offset=0" \
  -H "Authorization: Bearer pka_test_4b1c2d3e4f5g6h7i8j9k0l1m2n3o4p5q6r"
```

## Resolve your own project (project key)

<Endpoint method="GET" path="/api/v1/projects/me" auth="x-api-key" />

Returns the project behind the presented `x-api-key`. Handy when your integration only has the key and needs the project id for sub-resource routes.

```bash
curl https://dashboard.example.com/api/v1/projects/me \
  -H "x-api-key: pgk_test_4b1c2d3e4f5g6h7i"
```
