# Order events

<Endpoint method="GET" path="/api/v1/orders/{orderId}/events" auth="x-api-key" />

Returns the order's lifecycle as an ordered timeline, derived from the same
records the dashboard uses — useful for support tooling and reconciliation
loops that want the full history in one call.

## Example

```bash
curl https://dashboard.example.com/api/v1/orders/ord_3x4mpl3t3st0rd3r1d2/events \
  -H "x-api-key: pgk_test_4b1c2d3e4f5g6h7i"
```

## Event types

| Type | When |
|---|---|
| `order.created` | The order was created. |
| `receipt.submitted` | The customer uploaded a receipt. |
| `payment.approved` | The payment was approved (auto or manual). |
| `payment.rejected` | The payment was rejected. |
| `order.expired` | The order expired unpaid. |

`detail` contents vary per type and are informational — branch on `type`,
not on `detail` shape.
