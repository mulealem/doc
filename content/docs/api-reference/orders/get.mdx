# Retrieve an order

<Endpoint method="GET" path="/api/v1/orders/{orderId}" auth="x-api-key" />

Returns the current status of an order, including its payment (if any) and the extracted data from the receipt.

## Path parameters

<Params>
  <Param name="orderId" type="string" required>
    The order ID returned by [Create order](/api-reference/orders/create). Example: `ord_3x4mpl3t3st0rd3r1d2`.
  </Param>
</Params>

## Polling

This endpoint is the simplest way to poll for status. Suggested pattern:

```js
async function pollUntilTerminal(orderId, intervalMs = 2000) {
  while (true) {
    const order = await getOrder({ apiKey: API_KEY, orderId });
    if (order.status !== "PENDING") return order;
    await new Promise((r) => setTimeout(r, intervalMs));
  }
}
```

For production traffic, prefer [webhooks](/webhooks/overview) over polling — every status transition triggers a webhook event, so you don't need to budget the polling requests.

<Callout type="info">
  The `extractedData` object is included only when the payment reaches `APPROVED`. While the payment is in `PENDING` or `PROCESSING`, the `payment` object is `null` or missing the field.
</Callout>
